# Безопасность CodeBloodhound

Проверка кода и тестов от 21 ноября 2026 года. Прототип предназначен для синтетических учебных проектов в общем рабочем пространстве команды.

| Область | Что защищено | Что остаётся |
| --- | --- | --- |
| Доступ к демо | Прокси проверяет общий пароль или приглашение перед выдачей редактора и доступом к API. Приглашение обменивается на cookie с `Secure`, `HttpOnly` и `SameSite=Lax`. Запуск демо привязывает FastAPI и прокси к localhost. | Доступ общий для всей команды, включая историю и настройки. Персональные роли, разделение данных и отзыв конкретного приглашения отсутствуют. Смена общего пароля отзывает все ссылки и cookie. FastAPI сам не проверяет пользователя, поэтому публичный доступ должен идти через защищённый HTTPS-прокси. |
| ZIP и репозитории | Код проекта читается статически из ZIP, без запуска Gradle или исходников. Проверяются размер файла, суммарный размер, число записей, пути, дубликаты, симлинки, шифрование и CRC. Импорт по ссылке разрешён только для точных репозиториев из серверного списка. Бэкенд сам строит URL для `codeload.github.com`, блокирует редиректы, ограничивает размер и время скачивания. | Оператор проверяет назначение и содержимое репозиториев в списке. ZIP-загрузку для рабочего пространства нужно использовать только с учебными проектами. |
| Хранение и секреты | Детектор секретов сохраняет тип, файл и строку без найденного значения. Ключи LLM и адреса webhook передаются серверу через его конфигурацию. | Загруженные ZIP и отчёты хранятся в PostgreSQL без шифрования на уровне приложения. Политики удаления, изоляции пользователей и Vault отсутствуют. Если секрет записан в имени файла, путь сам может содержать чувствительные данные. |
| AI и внешний трафик | Ключ провайдера остаётся на сервере, DeepSeek требует согласия в API. Модель получает данные о находках, а пути фильтруются перед запросом. Ссылки карточек берутся из отчёта. Валидатор сверяет явные CVE, GHSA и ссылки вида `файл:строка`. При повторном некорректном ответе карточки строятся по правилам сканеров, а чат убирает недостоверный ответ. | Фильтр не проверяет истинность всех текстовых утверждений модели. При использовании внешней модели и публичных туннелей передавать только разрешённые учебные данные. |
| Webhook | Адрес назначения задаёт оператор на сервере. Через ноду выбирается имя получателя. Редиректы выключены, задан таймаут. Передаются находки и AI-результаты активной ветки. | Уведомление не подписывается. Произвольные HTTP(S)-адреса допустимы для оператора, включая локальные приёмники. Для внешнего получателя нужен HTTPS и проверенная конфигурация назначения. |

Форма локального «входа» удалена из редактора, поскольку она принимала пароль без серверной проверки. Демонстрационный доступ по общему паролю и приглашению обеспечивается прокси. Развёртывание VPS этой проверкой не изменялось.
