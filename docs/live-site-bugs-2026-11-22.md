# Баги CodeBloodhound на публичном сайте

Проверено 22 ноября 2026 на [topsecretapi.online](https://www.topsecretapi.online/) в браузере. Тестирование шло в гостевом режиме приложения, на ширине 1280 px и с проверкой первого экрана на 390 px.

## 1. Новый сценарий стирает несохранённый граф без предупреждения

**Приоритет P2.** Можно потерять проделанную работу в редакторе.

1. Открыть редактор с начальным сценарием «Проверка секретов».
2. Изменить название сценария и добавить ноду «Статический анализ».
3. Выбрать **Файл → Новый сценарий** до сохранения.

**Фактически.** Редактор сразу заменяет текущий граф пустым и показывает название «Новый сценарий». Несохранённые правки пропадают без предупреждения и возможности отменить переход.

**Ожидается.** При несохранённых правках редактор предлагает сохранить сценарий, продолжить без сохранения или отменить переход.

Код: [`frontend/app.js`](../frontend/app.js#L609).

**Тот же сбой при открытии AI-черновика.** Получить черновик в чате, переименовать текущий сценарий, добавить ноду и нажать **«Открыть на холсте»** в карточке черновика. Текущее название и граф сразу заменяются сгенерированными. Проверку несохранённых правок нужно применять и к этому переходу. Код: [`frontend/app.js`](../frontend/app.js#L1387).

## 2. При открытии настроек фокус остаётся на фоне и выходит из окна

**Приоритет P2.** Пользователь клавиатуры может продолжить навигацию по фоновому редактору, пока настройки его перекрывают.

1. Открыть **Настройки**.
2. Проверить, какой элемент получил фокус.
3. Перевести фокус на **Сохранить и проверить** и нажать **Tab**.

**Фактически.** При открытии фокус остаётся на кнопке с шестерёнкой. После нажатия **Tab** с последней кнопки фокус выходит из окна, хотя настройки остаются открытыми. Окно также не объявляется диалогом.

**Ожидается.** Фокус перемещается в диалог при открытии. **Tab** и **Shift+Tab** перемещают его внутри диалога. При закрытии фокус возвращается на кнопку настроек.

Код: [`frontend/index.html`](../frontend/index.html#L131).

## 3. Порты графа недоступны с клавиатуры

**Приоритет P2.** Без мыши или жестов нельзя собрать сценарий со своими связями.

1. Открыть начальный сценарий с нодами «Запуск», «Поиск секретов» и «Условие».
2. Попробовать перейти клавишей **Tab** на выход «Запуска» или вход «Поиска секретов», чтобы соединить ноды.

**Фактически.** Фокус пропускает порты. В проверенном интерфейсе они отрисованы как `span` без роли кнопки и с `tabIndex = -1`. Отдельной команды для создания связи с клавиатуры нет.

**Ожидается.** Порты можно выбрать с клавиатуры и соединить с помощью **Enter** или **Пробела**, либо создать связь через отдельный доступный диалог.

Код: [`frontend/app.js`](../frontend/app.js#L158).

## 4. AI добавляет лишнюю ноду «Источник» при явном ограничении состава графа

**Приоритет P2.** Черновик нарушает ограничения запроса. В данном случае появился лишний узел настройки области сканирования.

1. Выбрать локальную `qwen3:8b` и отправить в помощник: «Создай простой ручной сценарий проверки учебного Kotlin-проекта на секреты. Только запуск и поиск секретов, без условий, уведомлений и других нод».
2. Дождаться карточки черновика и проверить список нод. Затем нажать **«Открыть на холсте»**.

**Фактически.** Карточка и холст содержат `Запуск → Поиск секретов → Источник`.

**Ожидается.** Черновик содержит ровно `Запуск → Поиск секретов`. Сканер использует проект, выбранный в панели «Проект».

На `qwen3:4b-instruct` отдельный запрос с прямой фразой «отдельную ноду „Источник“ не добавляй» дал правильные две ноды. Результат зависит от модели и формулировки. Исходный запрос приведён дословно для повторной проверки.

## 5. AI подменяет «больше 2» на «больше или равно 2»

**Приоритет P2.** При ровно двух находках граф может пойти по ветке «Да», хотя пользователь запросил ветку «Нет» для этого случая.

1. С локальной `qwen3:8b` отправить: «Создай сценарий ежедневной проверки учебного Kotlin-проекта в 09:00 по Москве. Нужны только три ноды: Запуск по расписанию, Поиск секретов и Условие: число находок больше 2. Источник берётся из панели „Проект“, отдельную ноду „Источник“ не добавляй. Не добавляй другие ноды».
2. Нажать **«Открыть на холсте»**. Открыть инспектор ноды «Условие» или **Файл → Экспорт (JSON)**.

**Фактически.** Расписание `09:00 Europe/Moscow`, три ноды и порог `2` совпадают с запросом. В настройках выбрано **«Больше или равно»**, в JSON записано `"comparison": "ge"`.

**Ожидается.** Выбрано **«Больше»**, в JSON записано `"comparison": "gt"`. При двух находках условие ложно, при трёх истинно.

Проверены экспорт и выбранное значение в инспекторе. Ручной запуск на архиве с 11 находками успешно дошёл до условия, но это количество выше обоих порогов. Граничный случай на публичном сайте не запускался. Сравнения `gt` и `ge` реализованы отдельно в [`backend/conditions.py`](../backend/conditions.py#L11).

## 6. Настройки ошибочно требуют открывать редактор только с localhost

**Приоритет P3.** Подсказка может направить пользователя публичного сайта на заведомо неподходящий для него адрес.

1. Открыть публичный сайт и убедиться, что в шапке написано «бэкенд на связи».
2. Открыть **Настройки** и прочитать подсказку у адреса бэкенда.

**Фактически.** Подсказка утверждает, что редактор необходимо открывать с `http://localhost:5173` или `:3000`, иначе запросы отклонит CORS. На публичном адресе в той же вкладке успешно работали запуск проверки и AI.

**Ожидается.** При работе на публичном адресе подсказка описывает текущий адрес API. Инструкция про localhost показывается при локальном запуске.

Код: [`frontend/index.html`](../frontend/index.html#L133).
