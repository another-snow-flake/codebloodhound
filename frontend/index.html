Для этого сайта используйте адрес API по умолчанию. При локальном запуске укажите адрес своего бэкенда.

Список моделей, адреса и ключи задаются на бэкенде. Адреса webhook тоже настраиваются там, получатель выбирается в ноде «Уведомление».

Сценарий по описанию

Модели передаётся описание. Используйте учебные данные без токенов и паролей.

Область проверки:

    Черновик заменит текущий граф на холсте. Чтобы сохранить текущие правки, сначала закройте окно и сохраните сценарий.

    Своя нода

    Плагин — отдельный маленький проект. После этого окна откроется редактор: в нём уже стоят ноды «Вход» и «Выход» по числу портов, между ними соберите сканеры, условия и другие шаги.

    Другие пользователи увидят описание и настройки ноды, включая заметку, и смогут добавить копию.

    Вход

    Вход открывает новое рабочее пространство. Текущий сценарий можно сохранить перед переключением.
