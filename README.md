# CodeBloodhound

Проект для Cyber Garden 2026 · A Cyber Garden 2026 project

## Русский

Делаем конструктор проверок безопасности для учебных проектов на Kotlin, Spring Boot и Gradle. Сейчас можно загрузить ZIP, собрать сценарий через API и запустить поиск зашитых паролей, токенов и ключей. Отчёт показывает, в каком файле и на какой строке найдена проблема.

Бэкенд работает на FastAPI и PostgreSQL. Как запустить его и проверить на примере — в [BACKEND.md](BACKEND.md).

## English

We're building a security workflow editor for Kotlin, Spring Boot, and Gradle training projects. Right now you can upload a ZIP, set up a workflow through the API, and scan for hardcoded passwords, tokens, and keys. The report shows the file and line number for each finding.

The backend uses FastAPI and PostgreSQL. See [BACKEND.md](BACKEND.md) for setup and an example run (in Russian).
